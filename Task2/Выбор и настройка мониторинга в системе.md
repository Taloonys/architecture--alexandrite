# Мотивация
* Хоть для поиска застрявших заказов можно использовать некоторые механизмы RabbitMQ, но этого может быть недостаточно, учитывая рост поступаемых заказов и клиентов. 
* Метки времени и жизни состояний проще и правильнее будет хранить в ELK, QA может подсказать, как автоматизировать механизмы алертинга застрявших запросов
* Переход на более надёжное в таком плане решение - Kafka ожидается нескоро, а проблема проявляется уже на ранних этапах расширенного охвата рынка.
* Если команда и система будут расти, то системе мониторинга потребуется только модификации метрик

# Целевые метрики
* Number of dead-letter-exchange letters in RabbitMQ :: Основной показатель в брокере, по которому мы можем высматривать застрявшие сообщения
* Number of message in flight in RabbitMQ :: Потребуется для реконфигурирования Backpressure
* Базовые метрики для мониторинга предоставляемых API
    * Number of requests (RPS) for CRM API
    * Number of requests (RPS) for MES API
    * Number of requests (RPS) per user for internet shop API
    * Number of requests (RPS) per user for CRM API
    * Number of requests (RPS) per user for MES API
    * Memory Utilisation for shop API
    * Memory Utilisation for CRM API
    * Memory Utilisation for MES API
    * Response time (latency) for shop API
    * Response time (latency) for CRM API
    * Response time (latency) for MES API
    * Number of HTTP 200 for shop API
    * Number of HTTP 200 for CRM API
    * Number of HTTP 200 for MES API
    * Number of HTTP 500 for shop API
    * Number of HTTP 500 for CRM API
    * Number of HTTP 500 for MES API
    * Number of HTTP 500 for shop API
* CPU % for MES API :: Огромные расчёты, стоит задуматься, а может ли N-кол-во непростых запросов превысить вычислительные возможности инстанса
* Size of S3 storage :: Огромные модели попадают в БД, и это надо как-то отслеживать в избежании истощения ресурса
* Метрики API для возможно статистического анализа и реконфигурирования в Backpressure
    * Kb provided (sent) for shop API
    * Kb provided (sent) for CRM API
    * Kb provided (sent) for MES API
